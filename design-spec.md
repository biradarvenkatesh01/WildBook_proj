# WildBook design spec (images 01 to 20)

Build the frontend from these images, in order. Backend, schema and phases are in `project.md`.
Images 21 to 24 (Site Owner panel) and the logo sheet will be added later. Leave routes for them as stubs.

## How to use these images

1. The images are **visual references**, not pixel-exact specs. Match palette, type, spacing, card style and layout.
2. Each image was generated separately, so small details differ between pages. **Do not copy those differences.** Use the shared rules below instead.
3. Build shared components first (Navbar, Footer, Sidebar, Card, Button, StatusBadge, Stepper), then pages.

## Shared rules (override per-image differences)

- **One Navbar for the user site.** Logged out: logo, Sanctuaries, Experiences, About, Conservation, Log in, Sign up. Logged in: logo, Home, Sanctuaries, My Bookings, avatar menu. Images show many different nav links, phone numbers and "Book a Safari" buttons. Ignore those.
- **One Footer** (dark green): logo and one line, columns Explore, Company, Support, social icons. Copyright year **2026**. Images show 2024 or 2025. Ignore.
- **One Admin sidebar:** Dashboard, My Sanctuaries, Activities & Slots, Guides & Vehicles, Bookings, Reports. Images show extra items (Users, Messages, Discounts, Staff, Inventory, Animals, Media). Ignore those.
- **One booking ID format:** `WB-000101` (see `bookings.booking_code`). Images show five different formats.
- Logo files come from the logo set (user, admin, owner). Do not redraw the logo from the images.
- Status badge colours: Confirmed green, Pending amber, Cancelled red, Past grey, Draft grey, Approved green, Rejected red.

## Fields shown in the designs that are not in the schema yet

Add these columns, or drop the UI element:

| Table | Add | Used by |
|---|---|---|
| `sanctuaries` | `contact_email`, `contact_phone`, `website`, `opening_time`, `closing_time`, `operating_days`, `best_time_to_visit`, `latitude`, `longitude` | images 05, 18 |
| `activities` | `description`, `duration_minutes`, `what_to_carry` | images 05, 06 |
| `users` | `profile_image` (optional) | images 04, 17 |

**Price breakdown (images 07, 08).** The designs show extra lines (vehicle charges, permit fee, service fee). The schema has only `price x people`. Simplest option: show one "Safari charges" line and the total. If you want the extra lines, add a fees column to `activities` or `slots` and store the sum in `bookings.total_amount`.

## Known flaws in the images (do not copy)

- Typos and garbled text inside several images (for example "S photos" in image 12 and garbled button labels in images 04 and 05). Use correct text.
- Dates are 2024 or 2025. Use real data from the database.
- Image 12: the Submit button overlaps the bottom edge of the card. Give the card proper bottom padding.
- Image 11: the page behind the modal shows a different booking list layout from image 10. Use the image 10 layout.
